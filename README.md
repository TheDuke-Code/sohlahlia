# Sohlahlia

En gård på landet där det odlas dahlior.
Hemsidan är byggd för att hjälpa folk att komma igång med att våga odla dahlior.

## https://theduke-code.github.io/sohlahlia/

## Sidor
Hem - Där hittar du info om vad Sohlahlia är
Våra Dahlior - Där listar vi dom enklasta och finaste dahliorna
Odlingsguide - Här är vår enkla guide för att odla dahlior
kontakt - Här är ett formulär du kan fylla i med frågor om du vill ha mer hjälp

## Tekniker
HTML
CSS - Flexbox - Grid - Media queries
Javascript - Mobilmeny (Hamburgarmenyn) och valideringen av formuläret
